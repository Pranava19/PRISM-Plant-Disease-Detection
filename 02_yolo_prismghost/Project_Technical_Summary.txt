1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
This project develops a lightweight, edge-deployable deep learning framework for
20-Class Plant Disease Object Detection. We modified the standard YOLOv8 architecture
by introducing a novel PrismGhost convolutional module to minimize computational
FLOPs while preserving fine spatial lesion patterns, paired with a Quad-Head
Detection network (P2, P3, P4, P5) specifically engineered to detect micro-scale
leaf lesions that standard 3-head detectors miss.

Key Innovations:
- PrismGhost Module: Primary standard convolution + cheap depthwise convolution,
  slashing parameter count to 2.25 Million and complexity to 10.8 GFLOPs.
- Quad-Head Detection: High-resolution P2/4 scale (160x160 feature maps) for
  early-stage tiny fungal and bacterial lesion detection.
- Unified 20-Class Dataset: Harmonized PlantVillage (lab) and PlantDoc (field) into
  a single collision-free 28,268 image dataset (80/10/10 split).
- Edge Deployment: Exported dynamic batching ONNX model (8.64 MB, 11.8 ms latency).

3. MODEL ARCHITECTURE & PRISMGHOST FORMULATION
--------------------------------------------------------------------------------
Architecture Backbone:
Input Image (640x640x3) -> PrismGhost Feature Pyramid (P1..P5) -> SPPF
Neck: Bi-directional Feature Pyramid Network (BiFPN-style)
Head: Quad-Head Detect
  - Head 0 (P2/4  - 160x160): Micro-Lesions (< 16x16 px)
  - Head 1 (P3/8  - 80x80)  : Small Fungal / Bacterial Spots
  - Head 2 (P4/16 - 40x40)  : Medium Leaf Patches
  - Head 3 (P5/32 - 20x20)  : Large / Whole Leaf Context

PrismGhost Mathematical Formulation:
- Primary Intrinsic Feature Map:
  Y' = SiLU(BatchNorm(Conv_kxk(X, Wp))),  Y' in R^(H' x W' x m),  m = ceil(c2 / ratio)
- Cheap Depthwise Feature Map:
  Y'' = SiLU(BatchNorm(DWConv_3x3(Y', Wc))), Y'' in R^(H' x W' x (c2 - m))
- Concatenated Output:
  Y = [Y', Y''] in R^(H' x W' x c2)

--------------------------------------------------------------------------------
6. KEY PRESENTATION / VIVA TAKEAWAYS
--------------------------------------------------------------------------------
1. Why PrismGhost? Standard convolutions generate many redundant feature channels.
   PrismGhost uses intrinsic features + cheap depthwise convs, cutting parameters
   to 2.25M while maintaining high accuracy.
2. Why Quad-Head (P2..P5)? Early-stage plant diseases appear as micro-lesions.
   Adding the P2/4 head (160x160) preserves high spatial resolution and prevents
   small lesion detection failure.
3. Edge Viability: Exported ONNX model (8.64 MB, 11.8 ms) enables deployment on
   agricultural drones, IoT cameras, and mobile applications.
